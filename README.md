# AspnetMicroservices

**Course-based implementation — not original design work.**
**Kurs temelli uygulama — özgün tasarım çalışması değildir.**

This repository is my hands-on implementation, written while following Mehmet Özkaya's .NET microservices course material (mehmetozkaya/AspnetMicroservices). The architecture, service boundaries, folder layout and technology choices follow the course. I keep it public for transparency about how I learned this stack — it should be read as a learning exercise, not as a portfolio project.

Bu repo, Mehmet Özkaya'nın .NET mikroservis kurs materyalini takip ederek yazdığım uygulamadır. Mimari, servis sınırları, klasör yapısı ve teknoloji seçimleri kursu takip eder. Bu yığını nasıl öğrendiğim konusunda şeffaf olmak için public bırakıyorum — portföy projesi olarak değil, öğrenme çalışması olarak okunmalıdır.

## What I practised here / Burada pratik ettiklerim

ASP.NET Core Web API · Docker & Docker Compose · RabbitMQ + MassTransit · gRPC · Ocelot API Gateway · MongoDB · Redis · PostgreSQL · SQL Server · Dapper · Entity Framework Core · CQRS with MediatR · Clean Architecture
